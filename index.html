Supabase接続設定

Project URLとPublishable keyを入力。Secret / service_role keyは絶対に入力しないでください。

公開までの手順

  1. Supabaseで無料プロジェクトを作成。
  2. 同梱の schema.sql をSupabase SQL Editorで実行。
  3. Project URLとPublishable keyを上に入力。
  4. 先生用タブでアカウント登録・ログイン。
  5. GitHub PagesにこのHTMLを公開し、学生URLを配布。
